# Reputation System

Reputation rewards sustained positive participation without making the game pay-to-win.

## Sources

| Source | Default points |
|---|---:|
| Game achievement | 4 |
| Community contribution | 8 |
| Economic activity | 3 |
| Governance participation | 5 |
| Social behavior | 2 |

## Levels

| Score | Level | Benefits |
|---:|---|---|
| 1-20 | Newcomer | Base access |
| 21-40 | Scout | Small voting and fee benefit |
| 41-65 | Contributor | Priority support, medium benefit |
| 66-85 | Veteran | Larger voting and fee benefit |
| 86-100 | Legend | Highest non-transferable reputation benefits |

Inactive accounts decay by 5% per month, with a floor of 1 point. Manual review and rate limits apply to high-impact reputation changes.

## Anti-Gaming

- Cap points per action family.
- Require manual review for disputed reports and unusually fast score changes.
- Keep history for the latest behavior records.
- Do not allow direct reputation purchase.
